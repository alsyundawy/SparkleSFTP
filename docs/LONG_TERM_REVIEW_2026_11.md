## (a) Executive Summary of Architectural Health

**Overall Verdict: Strong Production Core (`A-` Security & Concurrency Foundation, `B+` Long-Term Maintainability with Tracked Multi-Month Debt)**

SparkleSFTP maintains a clean, modular Swift 6 architecture across all 10 library targets (`src/Packages/`) and top-level `src/Features/` and `src/App/` composition layers:

- **Strict Acyclic Layering Holds (`Package.swift`):** `SparkleCore` imports only `Foundation`; `SparkleTransferEngine` interacts with networking and persistence purely through `RemoteFileSystem` closures and `TransferJournalProtocol` (`SparkleCore`) without importing `SparkleNetworking` or `SparklePersistence` (`CIRC-001`), and zero `src/Packages/*` modules import `SparkleFeatures` (`CIRC-002`).
- **Post-`0.2.0` Architectural & Reliability Upgrades Verified (`5c2c212` / [ADR-008](ADR/0008-multi-window-isolation-appkit-tab-chrome-76-themes-and-transfer-pipeline.md)):**
  - Window isolation (`AppEnvironment.makeWindowState()` + `FocusedValues`), native AppKit `WorkspaceTabStripRepresentable` + `TabBarActionButton` controls, `SparkleWindowConfigurator` (`Close`/`Minimize`/`Zoom` + `NSAppearance`), auto-hiding `QuickConnectBar`, scoped AppKit shortcuts, and removal of redundant `Local Shell` improved desktop ergonomics while keeping `NSTableView` hit-testing responsive.
  - Shared `NSLock`-protected EWMA `TransferSpeedMeter`, `64 KB` pipelined SFTP (`SFTPPipelinedTransfer`, `min(32, max(2, pipelineDepth * 4))`), `CurlClientHelper` resume `total=0` filtering, POSIX permission (`& 0o777`) & hidden dotfile folder transfers, upload resume (`resolveUploadResumeOffset`), and debounced pane auto-refresh resolved major transfer correctness anomalies.
- **SonarQube Status Explicit Gap Statement (`TD-08`):** Running `swiftlint lint --reporter sonarqube --quiet` produces valid Generic Issue Import JSON with `sonarqube_issues=0`. In this review we fixed `sonar-project.properties` (`sonar.projectVersion=0.2.0` matching `Info.plist`, switching invalid `sonar.swift.swiftlint.reportPaths` to `sonar.externalIssuesReportPaths=reports/swiftlint-sonarqube.json`). **Remaining Gap:** Neither a hosted SonarQube/SonarCloud server (`SONAR_HOST_URL` / `SONAR_TOKEN`), a `.github/workflows/sonarqube.yml` scanner step, nor `SWIFT_SWIFTLINT_ARGUMENTS` report emission in `.mega-linter.yml` is wired in CI yet.
- **Remaining Structural Debt (`TD-01`–`TD-15`):** Broad `@MainActor ObservableObject` surface (`AppState.swift`, `383` lines) & full `tableView.reloadData()` in `FilePaneTableView.updateNSView` (`TD-01`, `TD-04`); unwired live Docker container suite (`TD-02`); production signing/notarization/Sparkle Sandbox XPC mach-lookup entitlements + `generate_appcast` CI automation (`TD-03`, `TD-15`); and transfer/terminal hardening (`TD-05`–`TD-07`, `TD-09`–`TD-14`).
