## Non-Negotiable MVP Release Gate

Before cutting `v1.0.0`, every condition below must pass with empirical test evidence:

- [x] `apple/swift-nio-ssh >= 0.14.1` (`0.15.1`) pinned and verified (**CVE-2026-43798** mitigated).
- [x] `Clibcurl` locked to `ftp,ftps` protocols only (`CURLOPT_PROTOCOLS_STR`) without `libssh` (**CVE-2025-15224** mitigated).
- [x] All Keychain entries enforce `kSecAttrAccessibleWhenUnlockedThisDeviceOnly` (**CWE-312 / CWE-522**).
- [x] Host key mismatch blocks connection with explicit alert; `acceptAnyHostKey` does not exist in production code.
- [x] FTPS enforces `SecTrustEvaluateWithError` (chain, hostname, expiry, OCSP) with zero auto-downgrade to plain FTP.
- [x] Path traversal (`../`) and malicious symlink targets are rejected before local/remote write (**CWE-22 / CWE-59**).
- [x] Zero credentials or private keys in `OSLog` / Console.app output (**CWE-532**).
- [x] Actor reentrancy cancellation tests and 100-tab PTY teardown tests pass without leaks or crashes.
- [x] SHA-256 verification runs off `MainActor` in streaming `FileHandle` chunks.
- [x] Live encrypted loopback SSH/SFTP + `DirectTCPIP` port forwarding + `TLSCertificateValidator` X.509 rejection + Universal 2 (`x86_64 arm64`) `.app` & DMG packaging verified locally.
- [ ] Live Docker OpenSSH/vsftpd/ProFTPD regression run in container runtime environment (`Tools/TestServers/run-integration-tests.sh`).
- [ ] Production Apple Developer ID notarization (`xcrun notarytool submit`) & Sparkle Ed25519 appcast signing (`Tools/Release/notarize.sh`).
