## 🌟 Sorotan Utama Rilis (Highlights)

- 🗂️ **Tampilan Dual-Pane Native macOS**: Menampilkan berkas komputer lokal dan server jarak jauh secara berdampingan. Pindahkan berkas hanya dengan menyeret mouse (*drag-and-drop*) atau menggunakan tombol pintas.
- 💻 **Terminal SSH Terintegrasi (`SwiftTerm`)**: Eksekusi perintah di server langsung dari dalam aplikasi tanpa perlu repot membuka jendela Terminal Mac terpisah.
- 🔐 **Penyimpanan Kredensial Super Aman (Apple Keychain)**: Kata sandi dan kunci privat SSH Anda terlindungi rapat oleh sistem keamanan Keychain Mac dengan dukungan otentikasi Touch ID.
- 🚦 **Penyelesaian Konflik Berkas Cerdas (FileZilla-Style)**: File sudah ada di tujuan? Pilih tindakan terbaik dengan mudah: Timpa jika lebih baru, Lanjutkan sisa unduhan, Ganti nama otomatis, atau Lewati.
- 🌐 **Dukungan Berbagai Protokol Populer**: Kompatibel penuh dengan SFTP (SSH), SCP, FTP biasa, dan FTPS (FTP terenkripsi TLS modern).
- 📥 **Impor Sesi Mudah dari Aplikasi Lain**: Pindahkan riwayat koneksi Anda dari FileZilla XML maupun format INI hanya dengan beberapa klik.

## ✨ Apa yang Baru & Manfaat untuk Anda (What's New)

### 1. Pengalaman Jelajah Berkas yang Alami di Mac

SparkleSFTP dibangun khusus menggunakan teknologi asli macOS (SwiftUI dan AppKit). Antarmukanya terasa sangat menyatu dengan ekosistem Mac Anda:

- **Dukungan Multi-Tab (`⌘T`)**: Buka banyak folder server secara bersamaan dalam satu jendela tanpa membuat desktop Anda berantakan.
- **Pratinjau Cepat (Quick Look - Spasi)**: Sorot berkas teks atau gambar lalu tekan tombol `Spasi` untuk mengintip isinya seketika tanpa perlu mengunduhnya terlebih dahulu.

### 2. Mesin Transfer Cepat & Bisa Melanjutkan Unduhan (Resume)

Koneksi internet Anda terputus saat mentransfer berkas berukuran besar? Tidak perlu khawatir:

- **Lanjutkan Otomatis (Resume)**: SparkleSFTP mampu mendeteksi berkas parsial (`.part`) dan melanjutkan proses unduh/unggah dari posisi terakhir tanpa mengulang dari nol.
- **Unggah Aman (Atomic Upload)**: Berkas diunggah dengan ekstensi sementara terlebih dahulu, lalu diubah namanya secara instan begitu selesai. Menjamin berkas di server Anda tidak pernah rusak akibat transfer terputus.

### 3. Perlindungan Keamanan Tingkat Tinggi

Aplikasi dilengkapi dengan lapisan pelindung proaktif untuk memastikan keamanan sistem Anda:

- Mencegah bahaya peretasan jalur berkas berbahaya (*Path Traversal* / `CWE-22`).
- Menolak tautan pintasan palsu yang berisiko merusak sistem lokal (*Symlink Protection* / `CWE-59`).
- Memverifikasi sertifikat TLS dan sidik jari kunci server (*Host Key Verification*) untuk melindungi Anda dari penyadapan data di jaringan publik.

## 📥 Panduan Unduh & Instalasi Cepat (Ramah Pengguna macOS)

### Langkah 1: Unduh Berkas DMG

Unduh berkas instalasi **`SparkleSFTP-0.2.0-universal.dmg`** dari lampiran berkas rilis resmi GitHub.

### Langkah 2: Pasang ke Folder Applications

1. Klik dua kali berkas `SparkleSFTP-0.2.0-universal.dmg` untuk membukanya.
2. Seret (*drag-and-drop*) ikon **SparkleSFTP** ke folder **Applications**.
3. Buka SparkleSFTP dari Launchpad atau Finder.

### Langkah 3: Jika Muncul Pesan Keamanan macOS (Gatekeeper)

Karena rilis komunitas ini menggunakan sertifikasi mandiri (*ad-hoc build*), macOS mungkin menampilkan pesan peringatan saat pertama kali dibuka:

- **Cara Termudah**: Klik kanan ikon SparkleSFTP di folder *Applications*, lalu pilih **Open (Buka)**, kemudian klik **Open** pada jendela konfirmasi.
- **Melalui Terminal (Alternatif)**: Buka aplikasi Terminal bawaan Mac, lalu tempel perintah berikut:

  ```bash
  xattr -dr com.apple.quarantine /Applications/SparkleSFTP.app
  ```

## 🔒 Keamanan, Privasi & Integritas Berkas

SparkleSFTP menjaga data rahasia Anda dengan standar keamanan kelas dunia:

- **Zero-Cloud / 100% Lokal**: Tidak ada akun online, tidak ada pendaftaran cloud. Seluruh data sesi dan kredensial Anda 100% tersimpan di Mac Anda sendiri.
- **Verifikasi Checksum Berkas**: Pastikan integritas berkas unduhan Anda dengan memeriksa nilai hash SHA-256 resmi berikut:

```text
38f3aa12d8c69fca239b95a5888203baaf9cef0a75ad15e179a1ac0e8be2588c  SparkleSFTP-0.2.0-universal.dmg
```

*Perintah verifikasi di terminal Mac:*

```bash
shasum -a 256 SparkleSFTP-0.2.0-universal.dmg
```
