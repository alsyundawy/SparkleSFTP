## 🌟 Sorotan Utama Rilis (Highlights)

- ⚡ **Peluncuran Aplikasi Super Gesit (Lazy-Load Theme Catalogs)**: Startup dipercepat secara signifikan. Dari 76 tema bawaan, hanya tema Terang bawaan, Gelap bawaan, dan tema aktif pengguna yang dimuat saat aplikasi pertama kali dinyalakan. Sebanyak 74 tema lainnya dan pemindaian JSON tema kustom ditunda (_lazy-loaded_) hingga tab Tema di Pengaturan dibuka.
- 🪟 **Eliminasi SwiftUI View Invalidation Thrashing**: `MainWindowView` tidak lagi menghitung ulang seluruh pohon tampilan jendela saat progres berkas atau pesan status diperbarui. Komponen bilah status (`MainWindowStatusBar`) dan bilah transfer minimal (`MainWindowMinimizedTransferBar`) diekstrak menjadi subview independen.
- ⏱️ **Frekuensi Antrean Transfer Terkendali & Ter-koalesensi (10–15 Hz)**: Pembaruan progres transfer kini digabungkan dan dibatasi hingga kecepatan ideal ~12.5 Hz (jendela waktu 80ms), melenyapkan saturasi loop render SwiftUI saat mentransfer ribuan berkas kecil secara bersamaan.
- 🐧 **Ketahanan Transfer Lintas Platform (macOS <-> Linux/BSD)**:
  - **Toleransi SETSTAT POSIX**: Pada server Linux/BSD di mana pengguna non-root tidak memiliki izin mengubah `mtime` atau `chmod`, kegagalan `SSH_FXP_SETSTAT` kini ditangani sebagai peringatan non-fatal tanpa membatalkan transfer berkas.
  - **Penyaringan Metadata macOS Otomatis**: Berkas `.DS_Store` dan AppleDouble (`._*`) disaring secara otomatis saat mengunggah folder maupun pemindaian sinkronisasi direktori, menjaga server remote tetap bersih.
  - **Penulisan Berkas Sementara `.filepart` yang Tangguh**: Berkas yang sedang diunggah menggunakan ekstensi sementara `.filepart` dan pergantian nama atomik (_atomic rename_) setelah selesai, mencegah berkas rusak jika koneksi terputus.
- 🔍 **Instrumentasi Signpost Cold-Launch**: Penambahan penanda profil `os_signpost` (`ThemeInitialization`, `InitialDirectoryListing`, `WindowConfiguration`) untuk mempermudah analisis performa peluncuran di Apple Instruments.
- 🛡️ **Verifikasi Concurrency Swift 6 Penuh**: Lulus 100% dari 121 pengujian otomatis di 33 suite pengujian tanpa satu pun peringatan _data race_ atau _concurrency warning_.

## ✨ Apa yang Baru & Manfaat untuk Anda (What's New)

### 1. Peluncuran Awal Lebih Cepat & Hemat Memori

SparkleSFTP memiliki koleksi 76 palet tema warna berkualitas tinggi. Pada versi sebelumnya, seluruh 76 palet dan pemindaian berkas JSON kustom dimuat secara serentak ke dalam memori saat aplikasi dinyalakan. Di v0.4.0:

- Hanya palet aktif serta palet dasar terang dan gelap yang dimuat saat cold start.
- Pemindaian 74 palet tambahan ditunda hingga pengguna secara eksplisit membuka menu preferensi tema.
- Hasil: waktu peluncuran lebih cepat dan jejak alokasi memori awal berkurang drastis.

### 2. Antarmuka Jendela Utama Tetap Responsif saat Transfer Berat

Ketika mentransfer berkas berkecepatan tinggi atau direktori dengan ribuan berkas kecil:

- Bilah status dan progres transfer kini diisolasi ke dalam subview mandiri.
- Jendela utama tidak lagi memicu _invalidation pass_ penuh pada hierarki tampilan commander saat progres transfer bertambah.
- Penggunaan CPU UI tetap rendah dan interaksi navigasi berkas tetap mulus tanpa tersendat.

### 3. Pengiriman Berkas ke Server Linux & BSD Lebih Andal

Banyak server Linux/BSD di lingkungan produksi membatasi modifikasi atribut berkas (_POSIX mtime_ dan _chmod_) bagi pengguna non-pemilik. Pada v0.4.0:

- Kegagalan `SSH_FXP_SETSTAT` izin akses (_permission denied_) dicatat sebagai non-fatal tanpa menghentikan transfer berkas utama.
- Berkas sementara kini dinamai dengan pola `.filename.sparklesftp.<uuid>.filepart` dan diganti namanya secara atomik saat seluruh bita terkirim. Jika transfer terganggu, berkas parsial dapat dilanjutkan (_resume_) dengan aman tanpa merusak berkas asli di server.
- Berkas sistem lokal macOS seperti `.DS_Store` dan `._*` dilewati secara otomatis saat mengunggah folder, mencegah penumpukan berkas sampah tersembunyi di server tujuan.

## 📥 Panduan Unduh & Instalasi Cepat

### Langkah 1: Unduh Berkas DMG

Unduh berkas instalasi **`SparkleSFTP-0.4.0-universal.dmg`** dari rilis resmi GitHub.

### Langkah 2: Pasang ke Folder Applications

1. Klik dua kali berkas `SparkleSFTP-0.4.0-universal.dmg` untuk membukanya.
2. Seret (_drag-and-drop_) ikon **SparkleSFTP** ke folder **Applications**.
3. Buka SparkleSFTP dari Launchpad atau Finder.

### Langkah 3: Jika Muncul Pesan Keamanan macOS (Gatekeeper)

Karena rilis komunitas ini menggunakan sertifikasi mandiri (_ad-hoc build_), Anda dapat membukanya dengan:

- **Cara Termudah**: Klik kanan (atau `Control` + Klik) ikon SparkleSFTP di folder _Applications_, lalu pilih **Open (Buka)**, kemudian klik **Open** pada jendela konfirmasi.
- **Melalui Terminal (Alternatif)**:

  ```bash
  xattr -dr com.apple.quarantine /Applications/SparkleSFTP.app
  ```

## 🔒 Keamanan, Privasi & Integritas Berkas

- **Zero-Cloud / 100% Lokal**: Kata sandi dan kunci SSH Anda disimpan secara aman di dalam **Apple Keychain** fisik Mac Anda.
