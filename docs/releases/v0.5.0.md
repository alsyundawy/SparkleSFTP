## 🌟 Sorotan Utama Rilis (Highlights)

- 📌 **Manajer Markah & Riwayat Jalur (Bookmarks & Path History Manager)**:
  - Menyimpan markah jalur lokal maupun remote dengan ikon penanda, nama kustom, dan host identifier terisolasi.
  - Riwayat penelusuran ring buffer 20 entri per pane (`local` / `remote`) dengan menu lompat cepat (_quick-jump menu_).
  - Dialog manajemen markah lengkap untuk menambah, menghapus, menyunting, dan menyortir daftar markah.
  - Opsi **Penelusuran Tersinkronisasi (Synchronized Browsing)**: Saat aktif, navigasi folder pada satu pane akan secara otomatis menyinkronkan pane pasangannya apabila subdirektori relatif yang sama ditemukan.
- 🌲 **Bilah Sisi Pohon Direktori (Directory Tree Navigation Sidebar)**:
  - Bilah sisi hierarkis yang dapat diciutkan/dibuka secara independen untuk pane lokal dan remote.
  - Pemuatan subdirektori secara malas (_lazy evaluation on demand_) saat node diperluas guna mencegah pembekuan antarmuka pada pohon folder besar.
  - Resolusi symlink aman dari siklus rekursif (_cycle-safe symlink detection_).
  - Sinkronisasi pemilihan dua arah antara pohon direktori dan daftar berkas pane aktif.
- ⚡ **Peluncur Perintah Remote Cepat (Quick Remote Commands Runner)**:
  - Bilah perintah praktis yang menempel di bagian bawah remote pane aktif dengan pemilih prasetel cepat.
  - Prasetel perintah lintas platform bawaan untuk Linux (`systemctl status !`, `df -h`, `journalctl -u ! -n 50`), BSD (`service ! status`, `top -s 1`), dan macOS (`launchctl list`, `du -sh *`).
  - **Pencegahan Injeksi Shell Berstandar Tinggi (`RemoteCommandSanitizer`)**:
    - Substitusi placeholder bergaya WinSCP: `!` (berkas terpilih), `!/` (jalur remote aktif), `!?prompt:default?!` (input interaktif).
    - Menolak dan menyaring metakarakter berbahaya (`;`, `&&`, `||`, `|`, `&`, `\n`, `\r`, backticks, `$()`, `${}`) guna mencegah _command injection CWE-78_.
  - Pengiriman perintah langsung ke sesi terminal SwiftTerm SSH yang terautentikasi sehingga pengguna memiliki kontrol dan visibilitas interaktif penuh.
- 🐚 **Integrasi Direktori OSC 7 SwiftTerm (OSC 7 Directory Synchronization)**:
  - Mendeteksi sekuens pelarian OSC 7 (`\033]7;file://...`) yang dipancarkan oleh shell terminal aktif (zsh, bash, fish).
  - Secara otomatis memperbarui direktori remote commander pane mengikuti direktori kerja shell terminal saat bernavigasi dengan perintah `cd`.
- 📋 **Relokasi Log Aktivitas ke Bilah Sisi Kiri**:
  - Panel Log Aktivitas dipindahkan ke atas Manajer Koneksi di bilah samping kiri, memberikan ruang vertikal maksimal untuk dual-pane commander dan terminal.
  - Dilengkapi bilah pulihkan minimalis `[ ⌄ Tampilkan Log Aktivitas ]` saat diperkecil, serta tombol perkecil pada header log.
- 🌐 **Paritas Penuh Lokalisasi Bilingual (517 Kunci)**:
  - Menambahkan 27 kunci baru untuk Markah, Pohon Direktori, Perintah Remote, dan Log Bilah Sisi dengan paritas 100% antara `en.json` dan `id.json`.
- 💿 **Universal 2 Release Packaging**:
  - Biner rilis gemuk Universal 2 (`x86_64` + `arm64`) ditandatangani dan dibundel dalam berkas `SparkleSFTP-0.5.0-universal.dmg` (disertai `SparkleSFTP-0.5.0-universal.dmg.sha256`).

## 📥 Panduan Unduh & Instalasi Cepat

### Langkah 1: Unduh Berkas DMG

Unduh berkas instalasi **`SparkleSFTP-0.5.0-universal.dmg`** dari rilis resmi GitHub.

### Langkah 2: Pasang ke Folder Applications

1. Klik dua kali berkas `SparkleSFTP-0.5.0-universal.dmg` untuk membukanya.
2. Seret (_drag-and-drop_) ikon **SparkleSFTP** ke folder **Applications**.
3. Buka SparkleSFTP dari Launchpad atau Finder.

### Langkah 3: Jika Muncul Pesan Keamanan macOS (Gatekeeper)

Karena rilis komunitas ini menggunakan sertifikasi mandiri (_ad-hoc build_), Anda dapat membukanya dengan:

- **Cara Termudah**: Klik kanan (atau `Control` + Klik) ikon SparkleSFTP di folder _Applications_, lalu pilih **Open (Buka)**, kemudian klik **Open** pada jendela konfirmasi.
- **Melalui Terminal (Alternatif)**:

  ```bash
  xattr -dr com.apple.quarantine /Applications/SparkleSFTP.app
  ```

## 🔒 Keamanan, Privasi & Integritas Berkas

- **Zero-Cloud / 100% Lokal**: Kata sandi dan kunci privat SSH disimpan secara aman di dalam **Apple Keychain** fisik Mac Anda.
- **Sanitasi Perintah Remote**: Semua masukan perintah disaring secara ketat sebelum diteruskan ke sesi SSH untuk mencegah eksekusi kode berbahaya.
- **Integritas SHA-256**: Setiap berkas instalasi disertai berkas verifikasi `SparkleSFTP-0.5.0-universal.dmg.sha256` untuk memastikan integritas paket.
