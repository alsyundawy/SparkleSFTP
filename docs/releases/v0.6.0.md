## 🌟 Sorotan Utama Rilis (Highlights)

### 🔐 1. Vault Konfigurasi Kriptografis & Portabilitas Penuh (F-01)
- **Format Bundel `.sparkleconfig` & `.sparklevault`**:
  - Format portabel JSON (`.sparkleconfig`) untuk cadangan bersih tanpa rahasia.
  - Format biner terenkripsi terautentikasi (`.sparklevault`) dengan tajuk biner 46-byte (`SPKVAULT1`), garam PBKDF2 16-byte, nonce AES-GCM 12-byte, dan panjang payload 8-byte.
- **Kriptografi Standar Militer**:
  - Derivasi kunci PBKDF2-HMAC-SHA256 dengan **600.000 iterasi**.
  - Enkripsi simetris **AES-256-GCM** dengan validasi integritas tag autentikasi 16-byte dan pengikatan AAD (_Authenticated Additional Data_).
  - Pembersihan memori in-place (_constant-time zeroization_) pada kunci enkripsi dan buffer plaintext untuk mencegah serangan remanensi memori (CWE-226).
- **Pengimpor Multi-Sumber Cerdas**:
  - Mendukung impor profil koneksi dari FileZilla XML, WinSCP INI, OpenSSH config (`~/.ssh/config`), dan format JSON internal.
  - 4 kebijakan penyelesaian konflik: Lewati yang Ada (`.skipExisting`), Timpa (`.overwrite`), Simpan Keduanya (`.keepBoth`), dan Gabungkan Grup (`.mergeGroups`).
- **Pengukur Kekuatan Kata Sandi Interaktif**:
  - Komponen evaluasi entropi zxcvbn-style dengan indikator visual dinamis dan peringatan keamanan instan.

### ⚙️ 2. Registri Pengaturan Komprehensif 10-Tab & Pencarian Universal (F-02)
- **10 Tab Preferensi Lengkap**:
  - **Umum** (`PreferencesView`): Mode startup, konfirmasi dialog, integrasi sistem.
  - **Koneksi** (`PreferencesView`): Waktu habis soket, keepalive, algoritma cipher/KEX, batas percobaan ulang.
  - **Transfer** (`PreferencesTransfersTab`): Batas kecepatan unduh/unggah, auto pipeline concurrency (1–16), preservasi timestamp mtime/POSIX.
  - **Tema & Warna** (`PreferencesThemeTab`): Pemilih 40+ palet tema profesional, rasio kontras WCAG AAA.
  - **Bahasa & Lokalisasi** (`PreferencesLocalizationTab`): Bahasa Indonesia & English dengan paritas 100% (691 entri).
  - **Terminal** (`PreferencesTerminalTab`): Jenis font mono, ukuran font, scrollback buffer, bell style, opsi OSC 7 & OSC 52.
  - **Editor** (`PreferencesEditorTab`): Pemilih editor eksternal, unggah otomatis saat simpan, deteksi perubahan disk.
  - **Keamanan** (`PreferencesSecurityTab`): Interval Touch ID, pembersihan cache Keychain, batas waktu clipboard, privasi IP.
  - **Jaringan & Proksi** (`PreferencesNetworkTab`): Pengaturan proksi SOCKS5/HTTP, IPv6 preferensi, integrasi SSH agent.
  - **Sinkronisasi & Markah** (`PreferencesSyncBookmarksTab`): Mode komparasi, pola eksklusi glob, ukuran riwayat jalur.
  - **Arsip** (`PreferencesArchivesTab`): Format kompresi default, level kompresi, inspeksi toolchain eksternal.
  - **Pembaruan** (`PreferencesUpdatesTab`): Saluran rilis (Stable/Beta), interval pemeriksaan, deteksi pembaruan commit.
- **Pencarian Preferensi Universal**:
  - Bilah pencarian instan yang memfilter preferensi di seluruh tab secara real-time.
- **Ekspor/Impor & Reset Terisolasi**:
  - Ekspor/impor seluruh pengaturan ke berkas kamus JSON (`.json`).
  - Tombol reset ke bawaan per tab maupun menyeluruh dengan konfirmasi aman.

### ⚖️ 3. Mesin Pembanding Direktori Berkecepatan Tinggi (F-03)
- Pembanding direktori linier $O(N + M)$ berbasis peta ganda (dual hash map) yang membandingkan ribuan berkas dalam milidetik (<150ms untuk 10.000 item).
- Mengklasifikasikan berkas ke dalam 6 status diskrit:
  1. Identik (`.identical`)
  2. Hanya di Lokal (`.onlyLocal`)
  3. Hanya di Remote (`.onlyRemote`)
  4. Berbeda Ukuran (`.differentSize`)
  5. Lokal Lebih Baru (`.localNewer`)
  6. Remote Lebih Baru (`.remoteNewer`)
- Visualisasi warna latar dan lencana status pada tabel berkas kedua pane secara bersamaan.

### 📝 4. Pengawas Editor Eksternal & Sinkronisasi Balik Atomik (F-04)
- Penyimpanan staging terisolasi di dalam `~/Library/Caches/SparkleSFTP/remote-edit/` dengan izin direktori ketat `0700`.
- Pengawas perubahan berkas berbasis Darwin `DispatchSourceFileSystemObject` dengan pertahanan symlink `O_NOFOLLOW` dan debounce penulisan 500ms.
- Dialog konfirmasi unggah balik otomatis saat berkas remote disimpan dari editor eksternal (VS Code, Sublime Text, TextMate, Xcode, dll.).

### 🚀 5. Pembatas Kecepatan Transfer & Konkurensi Adaptif (F-05)
- **Token Bucket Rate Limiter**: Pembatasan bandwidth unggah dan unduh yang presisi dan mulus tanpa lonjakan CPU.
- **AutoPipelineController**: Penyesuaian kedalaman pipeline konkurensi transfer secara otomatis (1 hingga 16 thread paralel) berdasarkan throughput jaringan dan latensi RTT.
- **Kebijakan Percobaan Ulang Exponential Backoff**: Pemulihan cerdas dari kegagalan jaringan sementara dengan jeda bertingkat dan pembatalan aman.

### 🔄 6. Koordinator Sinkronisasi Folder Waktu Nyata (F-06)
- Koordinator aktor terisolasi yang mengawasi modifikasi folder lokal secara otomatis.
- Jeda debounce 1.5 detik untuk pengelompokan operasi disk multi-berkas.
- Dukungan pola pengabaian berkas glob (`.git`, `node_modules`, `*.DS_Store`, `*.tmp`).
- Dialog pratinjau dry-run sebelum sinkronisasi dimulai.

### 🏷️ 7. Perencana Ganti Nama Massal Berbasis Aturan (F-07)
- Mesin ganti nama berkas massal murni tanpa efek samping untuk panel lokal maupun remote.
- Mendukung pencarian dan penggantian string, ekspresi reguler (Regex), pengubahan huruf (UPPER, lower, Title Case), dan penomoran otomatis dengan token penghitung `[C]`.
- Pencegahan tabrakan nama berkas dan pemeriksaan keamanan traversal direktori sebelum dieksekusi.

### 🔒 8. Penghitung & Pemeriksa Checksum Multi-Hash (F-08)
- Komputasi streaming untuk hash MD5, SHA-1, SHA-256, dan SHA-512 dengan penggunaan memori konstan ($O(1)$) bahkan pada berkas gigabyte.
- Komparator hash cerdas dengan lencana kecocokan visual (Cocok / Berbeda / Menunggu).
- Prasetel perintah CLI remote otomatis untuk ekstraksi digest dari server (`sha256sum`, `md5sum`, `shasum`).

### 📦 9. Toolkit Arsip Aman & Penguatan Zip-Slip (F-09)
- Pembuatan dan ekstraksi aman arsip berkas format ZIP, TAR, dan GZ menggunakan sistem `/usr/bin/tar` dan opsi `7zz`.
- **Pertahanan Zip-Slip (CWE-22)**: Verifikasi ketat jalur ekstraksi relatif agar tidak keluar dari direktori tujuan.
- Batas keamanan dekompresi hingga 50.000 entri untuk menangkal serangan _zip bomb_.

### 🛡️ 10. Penguatan Keamanan Protokol FTPS (F-10)
- Penegakan opsi `CURLOPT_FTP_SKIP_PASV_IP = 0` guna mencegah manipulasi alamat IP pada transfer mode pasif.
- Penegakan proteksi data saluran TLS ketat `CURLUSESSL_ALL` (PROT P).

### 🎯 11. Integrasi Sistem & Produktivitas Lanjutan (F-11 s/d F-15)
- **SSH Agent Authentication Helper**: Integrasi soket agen SSH (`SSH_AUTH_SOCK`) dengan fallback ke kunci Keychain.
- **Layanan Integrasi Rsync**: Pembuatan perintah sinkronisasi rsync dengan opsi kompresi, delete, dan dry-run.
- **Pemulih Sesi Ruang Kerja**: Menyimpan dan memulihkan tab direktori yang dibuka sebelumnya tanpa menyambung otomatis ke jaringan.
- **Command Palette (⌘⇧P)**: Dialog pencarian tindakan, koneksi, markah, dan pengaturan bergaya Spotlight dengan navigasi keyboard penuh.
