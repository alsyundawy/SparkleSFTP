# 🚀 SparkleSFTP v0.7.0 — Protocols, Linux Server Tools, Security Shielding & Dual-Pane Architecture

> **Rilis Resmi macOS Universal 2 (Apple Silicon & Intel)**  
> _Versi 0.7.0 menghadirkan lompatan besar dalam arsitektur transfer berkas macOS: Editor Teks & Kode Internal TextKit 2 berkinerja tinggi dengan pewarna sintaks 52+ bahasa dan mesin otomasi skrip makro Lua terisolasi (⌘K), Arsitektur Dual-Pane Commander dengan pembaruan baris beranimasi halus via CollectionDifference tanpa kedipan dan integrasi seret-lepas (drag-and-drop) langsung ke Finder, Kriptografi Pasca-Kuantum (PQ-KEX) ML-KEM-768 & NTRU Prime, Paritas FTPS Enterprise dengan framer dinamis STARTTLS pra-koneksi SecTrust & OCSP/CRL serta inspektur sertifikat X.509 dan TOFU trust store, Pengontrol Layanan Linux systemd jarak jauh, manajer proses & kontainer Docker, kalkulator subnet IPv4 & CIDR offline bawaan (⌘⌥S), pelanjutan unggahan terpipa dengan verifikasi hash blok awalan 64 KB, pengaliran transfer langsung remote-ke-remote, laci terminal persisten dengan buffer PTY 16ms, terminal mandiri layar terpisah vertikal/horizontal, serta mitigasi menyeluruh kerentanan 2024–2026 (CVE-2024-6387 regreSSHion, CVE-2023-48795 Terrapin, CVE-2026-43798 swift-nio-ssh pin, Zip-Slip, dan karantina korupsi SQLite)._

## 🌟 Sorotan Utama Rilis (Highlights)

### ✍️ 1. Editor Teks & Kode Internal TextKit 2 & Mesin Makro Lua (⌘K)

- **Arsitektur Murni Swift TextKit 2 (ADR-0013)**:
  - Mengadopsi arsitektur native TextKit 2 modern menggantikan pustaka pihak ketiga eksternal, menghasilkan performa rendering subpixel tajam, memori ultra-hemat, dan integrasi penuh dengan tema antarmuka macOS.
  - Perhitungan baris dokumen nol-alokasi memori heap (`zero-allocation line count`) dengan traversal langsung pada byte UTF-8 `0x0A`.
- **Pewarna Sintaks 52+ Bahasa Pemrograman & Konfigurasi**:
  - Dukungan sintaksis komprehensif mencakup Swift, C/C++, Rust, Go, Python, JavaScript, TypeScript, PHP, Java, Kotlin, Ruby, Perl, Shell/Bash, SQL, HTML, CSS, Markdown, JSON, YAML, TOML, XML, Dockerfile, Nginx/Apache conf, Systemd unit, dan berkas konfigurasi sistem Linux lainnya.
- **Editor Notepad Tunggal Bersih & Toolbar Gelap Permanen**:
  - Toolbar atas gelap konsisten (`#21252b`) dengan aksen border bawah `#181a1f`.
  - Format notepad tunggal minimalis tanpa opsi tab dokumen untuk pengalaman menyunting berkas yang fokus, bersih, dan cepat.
- **Jendela Terminal Internal Diperbesar Layar Penuh (Sebesar Kotak Terminal Eksternal, Tanpa Perlu Sandi)**:
  - Tombol ikon terminal diperbesar (`macwindow.on.rectangle`) disematkan di sebelah kiri tombol "Buka Terminal" pada toolbar utama dan laci terminal, membuka jendela terminal internal berukuran 1020×660 pt langsung terhubung ke saluran PTY `SSHClientService` terautentikasi tanpa meminta kata sandi berulang. Dilengkapi multi-tab, pencarian riwayat buffer (`⌘F`), pembesaran font interaktif (`⌘+`/`⌘-`/`⌘0`), peluncur cuplikan perintah (Snippets), dan manajemen SSH Port Forwarding / Tunnel.
- **Katalog 80 Cuplikan Perintah Modern SRE & Sysadmin (`CommandSnippetStore.swift`, `SnippetsSheet.swift`)**:
  - Peningkatan dari 5 menjadi **80 cuplikan perintah terkurasi** dalam 10 kategori:
    - **Sistem (10)**: Pemantauan disk (`df -h`), beban sistem & uptime, memori (`free -h`), proses rakus CPU/RAM, arsitektur CPU, rilis OS/kernel, limit file descriptor, dan statistik vmstat.
    - **Jaringan (10)**: Porta mendengarkan (`ss -tulpn`), antarmuka IP, tabel routing, IP publik, kueri DNS (`dig`), header HTTP (`curl`), statistik soket, penelusuran rute, dan tes jangkauan TCP.
    - **Kontainer (10)**: Status Docker, pemantauan utilisasi kontainer, pembersihan sistem (`docker system prune`), log kontainer, akses shell kontainer, dan manajemen Docker Compose.
    - **Kubernetes (8)**: Daftar pod seluruh namespace, filter pod bermasalah/pending, urutan utilisasi CPU pod, aliran event kluster, pemantauan log pod, dan restart deployment.
    - **Layanan (8)**: Layanan gagal di systemd, restart & verifikasi Nginx, muat ulang daemon, cek layanan kritis, daftar timer aktif, dan pembersihan log journalctl.
    - **Diagnostik (8)**: Log jurnal sistem (`journalctl`), pelacakan percobaan login gagal SSH, analisis log akses/error Nginx, peringatan kernel (`dmesg`), dan sesi pengguna aktif.
    - **Keamanan (8)**: Status firewall UFW, daftar blokir Fail2Ban, soket proses mendengarkan, hak sudo, masa kedaluwarsa sertifikat SSL/TLS, token acak aman, dan verifikasi checksum SHA-256.
    - **Basis Data (6)**: Ping & processlist MySQL/MariaDB, sambungan aktif & ukuran basis data PostgreSQL, serta info memori & jumlah kunci Redis.
    - **DevOps (6)**: Status Git & cabang hulu, grafik commit ringkas, perubahan berkas terakhir, dry-run pembersihan, dan variabel lingkungan terfilter.
    - **Berkas (6)**: Pencarian berkas besar (>100MB), berkas diubah 24 jam terakhir, standarisasi izin web (`755`/`644`), pembuatan/ekstraksi arsip tar, dan peringkat folder terbesar.
  - Antarmuka lembar cuplikan dilengkapi pencarian teks seketika, filter chip kategori, tombol salin ke clipboard satu-klik (`NSPasteboard`), injeksi langsung ke terminal, dan pemulihan katalog bawaan.
  - Penggabungan otomatis cerdas (_auto-merge_) saat memuat konfigurasi pengguna yang sudah ada tanpa menghapus cuplikan khusus buatan pengguna.
- **Optimasi Kecepatan Login & Koneksi Setara v0.6.0**:
  - Pemulihan pembacaan direktori langsung berkecepatan tinggi pada `SFTPService.listDirectory` tanpa overhead antrean stream.
  - Penundaan operasi I/O penyimpanan profil dan pembaruan basis data host terpercaya ke proses latar belakang non-blocking pada `AppState.finalizeSuccessfulConnection`.
  - Eliminasi waktu tunggu resolusi CRL jaringan yang lambat pada `TLSCertificateValidator` dan pemangkasan listing direktori ganda pada `FTPService.connect()`.
- **Mesin Otomasi Makro Skrip Lua Terisolasi (`⌘K`)**:
  - Mesin eksekusi skrip terisolasi yang mengekspos API editor aman (`getText`, `setText`, `replaceSelection`, `getLineCount`, `insertText`, `clear`).
  - Utilitas manipulasi teks bawaan: pengubahan huruf kapital/kecil, pemangkasan spasi, pembersihan duplikasi baris, penomoran urut baris, pengurutan alfabetis, enkripsi/dekripsi Base64, dan pemformatan JSON rapi.
  - Isolasi sandbox ketat menolak pemanggilan fungsi sistem berbahaya (`os.execute`, `os.remove`, `io.*`, `require`, `dofile`) guna menangkal potensi eksploitasi eksekusi kode acak (CWE-94).
- **Pusat Utilitas Pengembang (Developer Tools Hub)**:
  - Pusat utilitas konversi Base64, URL percent-encoding, validasi & format JSON, penghitung hash kriptografis instan (SHA-256, SHA-512, MD5 via CryptoKit), konverter timestamp Epoch Unix <-> ISO-8859 UTC, serta pembersih baris kosong.

### 📂 2. Arsitektur Dual-Pane Commander, Animasi Diffable & Drag-and-Drop

- **Animasi Pembaruan Baris Halus (Diffable Data Source)**:
  - Mengimplementasikan `CollectionDifference` untuk pembaruan data tabel berkas tanpa kedipan layar (_flicker-free_), mempertahankan status seleksi baris dan posisi scroll pengguna saat polling folder berkala berlangsung.
- **Integrasi Seret-Lepas Native (Drag-and-Drop to/from Finder)**:
  - Panel berkas mendukung penerimaan berkas langsung dari jendela Finder macOS (`NSDraggingDestination`) untuk memulai transfer unggah instan ke server, serta mendukung penyeretan berkas lokal ke aplikasi luar (`NSDraggingSource`).
- **Bilah Remah Roti (_Breadcrumbs Bar_) Interaktif**:
  - Navigasi segmen direktori lokal dan remote yang dapat diklik langsung, dilengkapi riwayat jalur, aksi salin jalur, dan mode sunting teks manual.
- **Tombol Pintas Fungsi Klasik Commander (F3–F8)**:
  - Bilah fungsi klasik: F3 (Pratinjau/View), F4 (Sunting/Edit), F5 (Transfer Antar-Panel), F6 (Pindah/Ganti Nama), F7 (Folder Baru), F8 (Hapus Berkas).
- **Bilah Filter Kategori Cepat**:
  - Pencarian filter langsung berdasarkan kategori (Semua, Dokumen, Gambar, Arsip, Kode) maupun ekspresi pola liar (`*.log`, `.*`) dengan penghitung kecocokan berkas real-time.

### ⚛️ 3. Kriptografi Pasca-Kuantum (PQ-KEX) & Standar OpenSSH 10.x

- **Algoritma Pertukaran Kunci Hibrida Pasca-Kuantum**:
  - Mendukung standar NIST FIPS 203 ML-KEM-768 hibrida (`mlkem768x25519-sha256`) serta Streamlined NTRU Prime (`sntrup761x25519-sha512@openssh.com`).
  - Lencana visual status koneksi aman Pasca-Kuantum pada sesi SSH/SFTP aktif.
- **Sinkronisasi Dua Arah OpenSSH `known_hosts`**:
  - Pengurai berkas `~/.ssh/known_hosts` standar untuk entri biasa, pemisah koma, maupun format hash HMAC-SHA1 (`|1|salt|hash`) dengan isolasi TOFU.
- **Jembatan Soket SSH Agent (`SSH_AUTH_SOCK`)**:
  - Validasi soket domain Unix agen SSH lokal dengan resolusi kanonikal `realpath` dan pengamanan traversal tautan simbolik (CWE-59).
- **Deteksi Token Hardware FIDO2 / U2F Security Key**:
  - Deteksi otomatis kunci privat berbasis token perangkat keras (`sk-ssh-ed25519@openssh.com` dan `sk-ecdsa-sha2-nistp256@openssh.com`) dengan panduan diagnostik ke agen otentikasi.
- **Ekstensi Protokol SFTP OpenSSH Modern**:
  - Negosiasi ukuran paket dinamis (`limits@openssh.com`), telemetri kapasitas disk dan kuota inode (`statvfs@openssh.com`), sinkronisasi fisik disk server (`fsync@openssh.com`), duplikasi berkas zero-copy (`copy-data`), serta pengecekan hash jarak jauh tanpa transfer (`md5-hash` / `sha256`).

### 🔒 4. Paritas FTPS Enterprise & Perlindungan Sertifikat TLS

- **Framer Dinamis Explicit FTPS STARTTLS**:
  - Peningkatan koneksi port 21 secara dinamis via `ExplicitFTPSFramer` sebelum kredensial dikirimkan.
  - Validasi rantai sertifikat ketat `SecTrust`, pencocokan hostname, batas kedaluwarsa, dan verifikasi pencabutan sertifikat CRL/OCSP.
- **Inspektur Visual Sertifikat X.509 & Penambatan TOFU**:
  - Lembar inspeksi detail sertifikat X.509 (`CertificateInspectorSheet`) dengan status lencana, nama subjek, penerbit, masa berlaku, dan sidik jari SHA-256.
  - Aksi penambatan kepercayaan satu-klik (_Trust On First Use / TOFU_) ke penyimpanan aman `HostTrustStore`.
- **Dukungan Active Mode FTP (`PORT` / `EPRT`)**:
  - Opsi penanganan koneksi FTP mode aktif untuk lingkungan jaringan VPN atau firewall tertentu yang memblokir mode pasif.
- **Negosiasi Charset Bertingkat & Parser Windows IIS**:
  - Parser daftar direktori FTP toleran encoding (UTF-8 -> ISO-8859-1 -> Windows-1252 -> ASCII).
  - Dukungan format direktori FTP server Microsoft Windows IIS (`MM-DD-YY HH:MM(AM|PM)`).

### 🖥️ 5. Administrasi Server Linux & Diagnostik Sistem

- **Pengontrol Layanan Linux Systemd**:
  - Manajemen status, restart, dan reload layanan server (`nginx`, `apache2`, `php-fpm`, `mariadb`, `mysql`, `postgresql`, `docker`, `sshd`, dll.) dengan sanitasi argumen anti-injeksi shell (CWE-78).
- **Penjelajah Proses & Pemantau Kontainer Docker**:
  - Pengurai tabel `ps aux` dengan opsi penghentian proses aman (`kill -15` SIGTERM / `kill -9` SIGKILL) disertai proteksi PID sistem root (`PID <= 1`).
  - Pemantau kontainer Docker aktif dengan aksi restart, stop, dan penampil log per kontainer.
- **Penampil Log Real-Time & Konverter Izin POSIX**:
  - Penampil log server jarak jauh (`tail -f`) untuk berkas sistem utama (`/var/log/syslog`, `/var/log/nginx/error.log`, dll.).
  - Konverter izin berkas dua arah antara format simbolik (`rwxr-xr-x`) dan format oktal (`0755`), dilengkapi sakelar executable `chmod +x` dan pembatasan aman `0600`.

### 📡 6. Diagnostik Jaringan & Kalkulator Subnet IPv4 Offline (⌘⌥S)

- **Penguji Keterjangkauan Port TCP**:
  - Pengujian port TCP asinkron via `NWConnection` untuk port-port kritis server (22, 21, 990, 80, 443, 3306, 5432, 6379) dengan metrik latensi milidetik.
- **Kalkulator Subnet IPv4 & CIDR Bawaan (`⌘⌥S`)**:
  - Mesin kalkulasi subnetting offline native Swift 6 yang di-porting dari SubnetCalc for macOS karya `@alsyundawy`.
  - Menghitung network address, broadcast, netmask, wildcard mask, rentang host yang dapat digunakan, total host, kelas IP, dan kategori privat RFC 1918.

### 🚀 7. Mesin Transfer Terpipa, Verifikasi Blok Pelanjutan & Aliran Remote-ke-Remote

- **Penjadwal Transfer Prioritas Berkas Kecil (Shortest-Job-First)**:
  - Mencegah fenomena _head-of-line blocking_ dengan memprioritaskan berkas berukuran kecil di depan berkas raksasa.
- **Verifikasi Blok Awalan 64 KB pada Pelanjutan Unggahan**:
  - Memverifikasi kecocokan hash SHA-256 blok 64 KB pertama antara berkas lokal dan berkas parsial remote sebelum menyambung unggahan, mencegah penggabungan berkas korup jika berkas sumber telah berubah.
- **Mesin Transfer Langsung Remote-ke-Remote**:
  - Mengalirkan pemindahan berkas antar dua server remote berbeda melalui pipa sementara terisolasi dengan pelaporan progres ganda dan pembersihan otomatis.
- **Bilah Progres Transfer pada Dock macOS**:
  - Pembaruan dinamis lencana dan bilah progres transfer pada ikon Dock aplikasi SparkleSFTP selama proses transfer berjalan.

### 💻 8. Laci Terminal Persisten 16ms & Terminal Layar Terpisah Bergaya iTerm2

- **Laci Terminal Persisten**:
  - Mempertahankan instans `TerminalView` AppKit dan 10.000 baris riwayat scrollback saat laci dibuka atau ditutup.
  - Penggabungan data stdout PTY dalam jendela 16ms (~60 FPS) mencegah kemacetan antarmuka pengguna pada keluaran terminal berkecepatan tinggi.
  - Bilah pencarian teks terintegrasi dengan penyorotan kecocokan dan navigasi naik/turun.
- **Terminal Mandiri Layar Terpisah (`⌘⌥T`)**:
  - Pembagian layar vertikal (`⌘D`) dan horizontal (`⌘⇧D`) dengan sesi PTY mandiri per panel.

### 🛡️ 9. Mitigasi Kerentanan Keamanan 2024–2026

- **Audit Proaktif CVE-2024-6387 (regreSSHion)**:
  - Komponen `SSHServerAuditor` memeriksa banner identifikasi server OpenSSH saat negosiasi awal dan memperingatkan sysadmin jika server belum ditambal (`OpenSSH 8.5p1`–`9.7p1`).
- **Mitigasi Serangan Terrapin (CVE-2023-48795)**:
  - Penegakan negosiasi kunci urut ketat `kex-strict-c-v00@openssh.com`.
- **Penguncian Versi Dependensi Kritis**:
  - Pengepinan `apple/swift-nio-ssh` ke `>= 0.14.1` (CVE-2026-43798) dan `apple/swift-nio` ke `>= 2.100.0` (CVE-2026-28970).
- **Kekebalan Jalur Ekstraksi Zip-Slip (CVE-2026-52886/57233)**:
  - Validasi kanonikal terhadap seluruh entri arsip untuk mencegah penulisan di luar direktori target, dibatasi hingga 50.000 entri dan ukuran maksimal 4 GB.
- **Karantina Otomatis Korupsi SQLite & Pembersihan Berkas Sementara**:
  - Menjalankan `PRAGMA quick_check;` saat inisialisasi basis data; memindahkan otomatis basis data korup ke `.corrupt.<timestamp>` dan membangun skema baru yang bersih.
  - Pembersihan otomatis berkas parsial `.sparklesftp.*.filepart` yang kedaluwarsa lebih dari 7 hari.
- **Invarian Arsitektur Tanpa Kompromi**:
  - **Zero Qt Dependency**: 100% murni Swift 6, SwiftUI, dan AppKit tanpa pustaka C++ Qt eksternal.
  - **Zero Icon Tampering**: Menjaga integritas visual ikon aplikasi, token tema, dan simbol SF Symbols asli tanpa perubahan tak diizinkan.
