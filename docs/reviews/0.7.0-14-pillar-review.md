## 🔍 2. Detailed Inspection by Pillar

### Pillar 1: Bug Review

- **SJF Dynamic Worker Prioritization (`TransferScheduler.swift`)**: Small files ($\le 1\text{ MB}$) are prioritized ahead of multi-megabyte transfers within equal priority buckets, eliminating head-of-line blocking during bulk operations.
- **Pipelined Upload Resume Integrity (`TransferQueue+Resume.swift`)**: Verifies prefix 64 KB block SHA-256 against local source before appending partial transfers. Restarts from offset 0 if the prefix diverges, preventing corrupted spliced files.
- **AppKit Drag-and-Drop Ingestion (`InteractiveFileTableSupport.swift`)**: Accepts dropped files securely via `NSURL.filePathURL`, validating security scope before routing to `AppState.uploadDroppedFiles`.
- **Sandboxed Macro Execution (`EditorMacroEngine.swift`)**: Safe regex line processing handles multi-line buffers, empty documents, and edge-case line endings (`CRLF`/`LF`) without index out-of-bounds exceptions.

### Pillar 2: Syntax Review

- **Swift 6 Concurrency Mode**: Project enforces `swiftLanguageModes: [.v6]` across all targets.
- **Actor Isolation**: Explicit `@MainActor` applied to all UI-bound coordinators, SwiftUI views, and AppKit representables.
- **Sendability**: All transfer jobs, file models, configurations, and network telemetry structures conform to `Sendable`.
- **Zero Type Coercion Hazards**: Strict unwrapping and safe `guard let` bindings applied across all parsing routines.

### Pillar 3: Runtime Review

- **Structured Concurrency Migration (`SSHClientService+Helpers.swift`)**: Migrated legacy `DispatchQueue` timeout in `waitBounded` to Swift 6 structured concurrency with cooperative timeout cancellation via `ShutdownResumeOnceBox.setTimeoutTask`.
- **Terminal Buffer Coalescing (`TerminalSessionManager.swift`)**: Coalesced PTY stdout chunks into 16ms buffers (~60 FPS) with 32 KB capacity-retained buffers in `attachPTYChannel`, avoiding main-thread draw call thrashing.
- **Token-Bucket Bandwidth Limiter (`TransferRateLimiter.swift`)**: Asynchronous token consumption with cooperative sleep ensures background transfer throttling does not block worker threads.

### Pillar 4: Logic Review

- **8-Action Conflict Resolution Engine (`ConflictResolver.swift`)**: Evaluates upload and download collisions through 8 distinct policies: Overwrite, Overwrite if Newer, Overwrite if Size Different, Overwrite if Different Size or Newer, Resume, Rename, Skip, and Ask.
- **Directory Comparison 6-State Partitioning (`DirectoryComparison.swift`)**: High-performance $O(N+M)$ comparison accurately partitions files into identical, different size, local newer, remote newer, missing local, and missing remote.
- **Multi-Hop ProxyJump Directives (`ProxyJumpParser.swift`)**: Parses nested bastion strings (`jump1:22,bastion@jump2:2222,[::1]:2200`) and builds chained channel forwarders with strict sanitization.

### Pillar 5: Memory & Resource Review

- **Document Buffer Traversal (`EditorModels.swift`)**: Zero-allocation byte traversal in `EditorDocument.lineCount` searches UTF-8 byte stream single-pass over `0x0A`, avoiding memory-heavy `split(separator: "\n")` allocations.
- **Streaming Hashing & Decompression (`ChecksumService.swift`, `ArchiveService.swift`)**: Reads files in 64 KB chunks, maintaining a flat memory profile even when processing multi-gigabyte disk images or archives.
- **Cryptographic Memory Zeroization (`ConfigBundleCrypto.swift`)**: Sensitive cryptographic buffers and derived symmetric keys are zeroized immediately after encryption/decryption operations.

### Pillar 6: Dead Code Review

- **Feature Flag Activation (`RemoteServiceFactory.swift`, `AppState.swift`)**: Verified and wired `isSCPFallbackEnabled` (throws `AppError.invalidConfiguration` when disabled) and `isPortForwardingEnabled` (enforces tunnel activation rules).
- **Pruned Unused Stubs**: Compiler verified with `-warnings-as-errors` ensuring zero unreachable code blocks, unused local variables, or uncalled private functions.

### Pillar 7: Duplicate Code Review

- **Centralized UI Modals**: Unified modal close handling via `ModalCloseButton.swift` across all sheets (Certificate Inspector, Subnet Calculator, Batch Rename, Lua Console, Conflict Resolution).
- **Consolidated Settings Architecture**: Unified settings management in `SettingsRegistry.swift` and `AppState+Settings.swift`.
- **Centralized Password Strength Scoring**: `PasswordStrengthMeter` shared across Connection Editor, Export Sheets, and Master Password setups.

### Pillar 9: Performance Bottlenecks Review

- **Diffable File Pane Updates (`FilePaneTableView+Coordinator.swift`)**: Evaluates directory differences with `CollectionDifference`. For updates $\le 50$ items, performs animated row insertions/removals with `.effectFade`, eliminating table reload flicker and retaining scroll offsets.
- **Streaming READDIR AsyncSequence (`SFTPService+Listing.swift`)**: Emits remote directory items in 500-item chunks via `AsyncThrowingStream`, keeping memory bounded even on 100,000+ file folders.
- **Adaptive Transfer Windowing (`AutoPipelineController.swift`)**: Automatically scales in-flight transfer concurrency from 1 to 16 based on RTT measurements and socket error rates.

### Pillar 10: Security Vulnerability Review (OWASP & CWE)

- **CVE-2024-6387 (regreSSHion)**: `SSHServerAuditor` flags vulnerable OpenSSH versions (`8.5p1`–`9.7p1`) during banner exchange.
- **CVE-2023-48795 (Terrapin)**: Strict key exchange extension negotiation resets sequence numbers during handshake.
- **CVE-2026-42214 (Lua Macro Sandbox Escape)**: `EditorMacroEngine` strips `os.execute`, `os.remove`, `io.*`, `package.loadlib`, `require`, `dofile`, `process`, and `shell`.
- **CVE-2026-52886 & CVE-2026-57233 (Zip-Slip & Symlink Traversal)**: `ArchiveService` validates canonical extraction roots, rejecting entries with `..`, leading slashes, or targets escaping extraction bounds. Enforces 4 GB extraction ceiling and 50,000 entry limit.
- **CVE-2026-8932 (mTLS Connection Reuse)**: `CurlClientHelper` enforces `CURLOPT_FRESH_CONNECT = 1` and `CURLOPT_FORBID_REUSE = 1`.
- **CVE-2025-15224 (Protocol Downgrade)**: `CurlClientHelper` locks allowed protocols to `kAllowedProtocols = "ftp,ftps"` via `CURLOPT_PROTOCOLS_STR`.
- **CVE-2026-105925 (XML Billion Laughs / DoS)**: `ExternalImporters` enforces 16 MB document size ceiling and disables external DTD resolution.
